# Land Assistant Android releases

Android APK downloads and the in-app update feed for Land Assistant Preview.

The Android update channel is published on the `android-preview-updates` branch. In the app, open **App updates** to check the available version, read what is new, and choose **Download update** or **Later**. Android asks for installation confirmation.

Install updates over the existing Preview app. Do not uninstall to update: uninstalling removes locally saved records. This channel keeps the package `in.landverification.preview` and one stable signing certificate.

APK SHA-256 and the signing-certificate SHA-256 are recorded in `update.json`. No portal accounts, cookies, OTPs or land records are uploaded here. The app source and signing key are not published in this repository.
